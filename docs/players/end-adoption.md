# How to end an adoption

Either a parent or their child can end **their direct connection**. The other person's consent and a priest are not required.

1. Run `/faith relationships` and choose **End adoption**.
2. Select the parent or child whose connection you want to end.
3. Check the two heads, then choose **End adoption** to confirm. Press **Esc** to leave it unchanged.

<!-- Screenshot: End adoption confirmation showing Parent and Child. -->

That connection disappears from the active [family tree](family-tree.md). Other parents and children stay connected. If the child has several parents, each connection is ended separately.

Once the child has **no active parents**, they can [be adopted again](adoption.md).

??? info "Does this erase the old family history?"

    No. Beliefs retains ancestry for its relationship safeguards. Ending an adoption does not allow former relatives to marry, or allow a later adoption to create an ancestry loop.

??? tip "I cannot see End adoption"

    The button appears when you have an active parent or child connection. For an unfinished request, use `/faith pending` → **Cancel request** or **Decline** instead.

Shortcut: `/faith unadopt <player>` opens the confirmation for that parent or child.

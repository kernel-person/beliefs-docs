# Permissions

These are the permission nodes declared by Beliefs.

| Permission | Default | Allows |
| --- | --- | --- |
| `beliefs.use` | Everyone | Use Beliefs commands and menus. |
| `beliefs.create` | Everyone | Create a faith (also requires `beliefs.use`). |
| `beliefs.admin` | Operators | Use `/faithadmin` administration commands. |

Faith roles are separate from server permissions. Being an operator does not make you a faith’s founder or clergy. Founders edit doctrine; clergy handle their permitted community tasks.

Use your server’s permission manager to grant or deny these nodes. See [Commands](commands.md) and [People & places](../leaders/people-and-places.md).

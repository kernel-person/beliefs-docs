# Credits

Beliefs is a Minecraft plugin by Rickard.

The symbol gallery uses the custom pixel artwork supplied for Beliefs’ 22-head catalogue. The pictures show the symbol faces; Minecraft displays them on player-head items. Symbol names identify artwork, not a complete definition of any real-world religion.

The marriage recipe illustration is generated from Beliefs’ bundled recipe configuration. It is a diagram, not an in-game screenshot. Servers can customize the recipe.
